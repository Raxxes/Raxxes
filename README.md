## ◈ WHO'S BEHIND THE CODE?

I'm a Computer Science & Engineering diploma student and self-taught developer who enjoys turning ideas into clean, interactive and meaningful digital experiences.

My current centre of gravity is **backend development with PHP, Laravel and SQL**. I also enjoy shaping the frontend, exploring new tools and understanding how complete products fit together — from the first interface to the data behind it.

- 🎓 Studying Diploma in Computer Science & Engineering
- ⚙️ Main focus: PHP, Laravel, SQL and practical backend development
- 🎨 Frontend toolkit: HTML, CSS, JavaScript, Bootstrap and React
- 🗄️ Databases: MySQL and SQLite
- 🧪 Exploring: AI, data science, computer vision and creative technology
- 🌱 Improving: DSA, software engineering and system design
- 🎯 Mission: Build useful products that solve real problems

> I learn best by building, breaking things, debugging them, and trying again.
